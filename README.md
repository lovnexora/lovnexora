### 04 / how i think about building

```text
problem
   ↓
understand the system
   ↓
build the smallest version
   ↓
break it
   ↓
measure what actually happened
   ↓
iterate
   ↓
ship
```

I prefer working from first principles over memorising abstractions.

A framework is useful.

Knowing why it works is better.
